# Mode: quiz — Drill the corpus

Ask EN, grade IT. This mode defines what "correct" means, which makes it the
mode most worth getting exactly right — a lenient grader teaches you wrong
Italian, a brittle one teaches you to hate the tool.

> **Non-negotiables (from `AGENTS.md`):**
>
> - **Grade against `it` only.** `alternates[]` are shown, never scored.
> - **Never edit the corpus mid-drill.** A quiz session is read-only against
>   `data/traduzioni_v2.json`. Corrections are queued and offered at the end.
> - **Never rewrite a graded answer because the user disagreed with it.** That's
>   a `translate` promotion, done deliberately, not a grading side effect.

## Input

`$mode` after `quiz` is optional scope:

- **nothing** → 10 entries, weighted by the selection rules below
- **a count** (`"quiz 5"`)
- **a filter** (`"quiz nouns"`, `"quiz child"`, `"quiz farm"`, `"quiz Evie"`)
- **`reverse`** → show Italian, ask for English (easier; use sparingly)
- **`gender`** → show the Italian noun bare, ask only for the article

## Pipeline

1. **Load.** Read `data/traduzioni_v2.json`. Parse or stop.

2. **Select.** Filter by scope, then order:
   - Entries never drilled, first.
   - Entries missed last session, next.
   - Then random. Never the file's storage order — position is not difficulty,
     and drilling in file order means the last-added entries never come up.

   If a filter matches nothing, say so and offer the nearest filter that does.
   Do not silently fall back to the whole corpus.

3. **Render the prompt.** Show `en`. For templates, fill `{name}` with the
   default entity's `it_name` — drill the sentence you'd actually say, not the
   skeleton. Show `register` when it changes the answer, in parentheses. Do not
   show `gender` — that's part of what's being tested.

4. **Take the answer.** One line from the user. Then grade.

5. **Grade.** See below. State the verdict, then the graded answer, then the
   alternates. Keep it to three lines.

6. **Move on.** No praise, no commentary between items. Terse is the whole
   contract.

7. **Report at the end.** Score, the missed items, and any queued corrections.

## Grading

Compare the user's answer to `it`. Normalize both first: trim, collapse internal
whitespace, case-insensitive, strip trailing punctuation.

Then, in order:

**Exact** → correct. Done.

**Article wrong or missing** → _not_ correct, but say precisely why.
`"carriola"` for `"la carriola"` is a miss, and it's the most important kind of
miss in the whole corpus. Gender is what's actually hard about Italian nouns;
letting the article slide teaches the wrong lesson. Report as
`"la carriola — the article is the point"`.

**Accents missing or wrong** → _not_ correct. `"piu"` for `"più"`, `"e"` for
`"è"`. Flag it as an accent miss specifically, so the user can see it's a
spelling slip rather than a vocabulary gap. These are the cheapest points in the
corpus to recover and they matter in writing.

**Matches an alternate** → _near miss_, not a failure. Say which alternate, and
that the graded answer is the other one. Count these separately in the final
score — a corpus where the user consistently answers with an alternate is a
corpus whose graded answer is arguably wrong, and that pattern is worth
surfacing at the end.

**Different but plausible Italian** → judge it. You are a master of both
languages; use that. If the answer is genuinely idiomatic for the English
prompt, mark it acceptable, say it isn't the filed answer, and offer to add it
to `alternates[]` after the session. If it's a calque or register-wrong, mark it
wrong and name the reason in one clause.

**Blank or "don't know"** → wrong, no penalty framing. Show the answer, move on.

## Output Format

```
1/10 — **wheelbarrow**

> la cariola

Near miss — that's an alternate. Graded: **la carriola**.
Also: il carrettino a mano · la barella da cantiere
```

```
3/10 — **it's time for bed** (child)

> Evie, è ora di andare a letto

Near miss — alternate. Graded: **Evie, è ora della nanna**.
```

```
7/10 — **hay**

> la paglia

Wrong — paglia is straw. **il fieno**.
```

End of session:

```
7 correct · 2 near miss · 1 wrong

Missed: hay (paglia/fieno confusion)
Near: wheelbarrow, bedtime — both times you answered the alternate.

Queue: add "la cariola" as graded for tr_wheelbarrow? You've now answered it
twice.
```

## Session State

The corpus file is read-only here. If you want drill history to persist across
sessions, write it to `data/quiz-log.jsonl` — one line per item, appended:

```json
{
  "ts": "2026-08-29T18:22:00Z",
  "id": "tr_hay",
  "result": "wrong",
  "given": "la paglia"
}
```

That's a **derived** file. It can be deleted and regenerated by drilling again;
nothing else reads from it as truth. It is never merged into
`traduzioni_v2.json`, and a corrupt or missing log never blocks a drill — start
fresh and say so in one line.

## Anti-Patterns

- Don't accept a bare noun for an entry whose `it` carries an article. The
  article is the tested content.
- Don't be encouraging. No "close!", no "nice one". Verdict, answer, next.
- Don't reveal the answer in the prompt by showing `gender` or `note`.
- Don't grade against `alternates[]` even when the alternate is better. If it's
  better, surface that at the end and let the user promote it deliberately.
- Don't edit the corpus during the session, including "obvious" typo fixes in
  entries you pass over. Queue it.
- Don't drill in file order.
